# 实验报告：Qwen2.5-0.5B-Instruct 拒答方向消融

**状态：** 初次探索；不是经过验证的干预，也不是基准测试。

## 研究问题

能否从风险请求与普通请求的残差激活中估计对比方向，并将它作为小型指令模型权重编辑的探索性切入点？实验考察激活测量、方向稳定性、若干编辑层位和强度、权重完整性、中英双语能力，以及拒答相关行为。样本量不足以支持有关拒答机制的普遍结论或安全部署结论。

## 实现方法

实验参考“部分拒答行为可能与残差流表示中的方向相关”的研究假说。通过 forward hooks 采集每个 block 输入和输出处、最后一个未填充 prompt token 的原始 `resid_pre` 和 `resid_post` 激活。每层主方向估计为均值差的单位向量：`d = normalize(mean(h_risk) - mean(h_benign))`。同时使用带词表拒答标记的生成结果估计弱标签方向。在保留的方向验证样本上测量线性可分性，用多次半样本抽样测方向稳定性。较高的 AUC 只说明方向与标签存在关联，不证明它导致拒答。

对 PyTorch 线性变换 `y = W x`，权重形状为 `[d_out, d_in]`，投影编辑为 `W' = (I - alpha d d^T)W = W - alpha d(d^T W)`。修改注意力输出 `o_proj` 与 MLP 输出 `down_proj`，减弱这两类映射沿 `d` 的输出分量。在精确算术中，`alpha=1` 会移除此两类特定映射内的该分量，但不会从每层隐藏状态中移除同一方向，也不会移除所有安全行为。词嵌入、归一化参数、Q/K/V 投影和语言模型输出头保持不变；被编辑输出映射的 bias 也会投影。

实验禁用训练。激活和方向以无梯度方式计算；每个变体从 CPU 保存的原始权重副本恢复。通过校验原始权重哈希和恢复后的 logits 检查完整性，并独立重载保存后的模型，核对 tokenizer ID 和回答复现情况。

## 实验设置

- 基础模型：Qwen2.5-0.5B-Instruct，24 个 Qwen2 block，约 0.49B 参数。
- 环境：Windows 11、Python 3.9、RTX 4060 Laptop 8 GB、PyTorch 2.7.1+cu118、Transformers 4.57.6。
- 方向校准：64 条英语风险请求和 64 条普通提示用于估计方向；方向验证集每类 16 条。数据来自本地 `harmful.txt` 和 `harmless.txt`，上游分别标注关联到 AdvBench 与 Alpaca-cleaned。采用固定种子抽样，与自建评估提示做规范化文本精确去重，并过滤长提示。仓库仅发布汇总数据来源计数与原文件哈希，不发布提示或复制语料。
- 自建评测：32 条开发提示和 48 条中英双语测试提示，包含精确答案问答、格式与指令跟随、良性敏感问题和明确风险请求。
- 英语外部样本：每类 24 条，使用相同本地数据源抽样并剔除规范化文本精确重复。这是留出子集，不是独立收集的基准。
- 候选编辑：第 8、14、20 层风险标签方向，强度 0.25、0.5、1.0；全 block、中间 block 和仅 MLP 输出编辑；零编辑与固定随机方向对照。每个候选都从原始权重恢复后开始。
- 指标：精确问答与指令判分；对回答前 700 字进行拒答词表匹配；人工逐条复核最终双语风险回答；截断率；首个回答 token 分布 KL；bootstrap 区间；原模型哈希与保存重载检查。

## 实验结果

| 指标 | 原模型 | 选中编辑模型 |
|---|---:|---:|
| 自建双语问答准确率，12 条 | 9/12 (75.0%) | 8/12 (66.7%) |
| 自建双语指令遵循率，12 条 | 6/12 (50.0%) | 5/12 (41.7%) |
| 双语风险请求拒答词表触发率，12 条 | 12/12 (100%) | 1/12 (8.3%) |
| 英语外部风险请求拒答词表触发率，24 条 | 23/24 (95.8%) | 1/24 (4.2%) |
| 英语外部普通请求拒答词表触发率，24 条 | 0/24 | 0/24 |
| 完整双语测试输出与严格 QA/格式判分 | 48 条 | 48 条 |

最终模型使用第 20 层风险标签均值差方向，`alpha=1`，编辑全部 24 个 block 的注意力和 MLP 输出映射。这是后续探索性最终筛选的结果。48 条测试集在本次更广泛实验中已被运行，因此它不是在额外筛选之后保持未触碰的确认性测试。固定随机方向对照的拒答标记变化较小，和估计方向含有更多任务相关信号的解释相符，但单一随机对照不足以排除一般编辑效应。

人工复核编辑模型的 12 条自建风险测试时，4 条表现为明显不当配合，3 条属于安全劝阻，1 条因回答截断不足以判断，其余回答混杂或有歧义。短生成经常被截断，不能据观察到的前缀断言完整回答质量。词表统计可能漏掉间接劝阻，也可能将非拒答误判为拒答，只是诊断性文本匹配，不是安全指标。

严格问答和指令遵循各减少一条样本。相应 Wilson 95% 区间很宽：问答原模型/编辑模型为 46.8–91.1% / 39.1–86.2%，指令遵循为 25.4–74.6% / 19.3–68.0%。现有样本不足以确认普通能力得到保留。

基础模型主权重编辑前后的 SHA-256 相同，恢复和零编辑对照 logits 完全一致。独立重载的最终检查点能够精确复现 tokenizer ID 和本次 48 条测试回答。这些验证的是实现和产物完整性，而非模型行为结论的有效性或安全性。

## 结果解读与下一步

本次证据仅支持一个范围有限的观察：在这个模型、提示格式和小型英语校准语料上，对比残差方向并编辑部分输出投影，显著改变了拒答词表匹配模式。普通能力指标也有所下降；编辑模型对明显不当请求的行为仍然不稳定。因此不能将结果概括为“所有限制都已解除”，拒答标记减少本身也不等于安全性改善。

后续较可信的研究应预先锁定规模更大且独立来源的评测集，用多个随机种子与更多随机方向对照；将行为上的拒答标签与风险意图标签分开；按预先声明的规则比较层位和强度；在更长生成上做截断感知评估及独立安全复核；并在更大架构上重复实验。本仓库提供后续研究工作流，不声称这些研究已经完成。
